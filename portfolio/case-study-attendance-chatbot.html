AI Attendance Chatbot —
Face Recognition + n8n + WhatsApp

Sistem kehadiran otomatis berbasis CCTV yang mengidentifikasi wajah pegawai & mahasiswa secara real-time, lalu menyebarkan informasi kehadiran melalui chatbot WhatsApp AI — tanpa menunggu respon manual.

📅 2026 🎯 Akurasi 86,16% ⚡ Latensi 15,9 dtk 🤖 Gemini 2.5 Flash
Lihat Source Code Hasil & Evaluasi

1 Masalah

Konteks nyata di lingkungan akademik.

❓ Situasi

  • Mahasiswa menunggu kepastian kehadiran dosen/pegawai untuk bimbingan skripsi.
  • Mengandalkan pesan singkat → respon lambat karena kesibukan pihak dihubungi.
  • Informasi kehadiran tidak real-time dan bergantung manusia.

💡 Solusi

  • CCTV + face recognition (InsightFace + MediaPipe) mendeteksi kehadiran otomatis.
  • Data tersimpan otomatis ke Google Sheets + bukti foto di Google Drive.
  • n8n mengorkestrasi alur — AI Agent (Gemini) menyampaikan info via WhatsApp.
  • Chatbot: cek kehadiran, bukti foto, dan request notifikasi otomatis.

2 Arsitektur Sistem

Alur data dari kamera CCTV hingga WhatsApp pengguna.

📹
Kamera CCTV (RTSP)

Tenda RP3-393A — stream video real-time ke modul Python.

▼
🐍
Modul Face Recognition (Python)

MediaPipe mendeteksi wajah → InsightFace (Buffalo_L) ekstraksi embedding 512D → Euclidean distance vs dataset → Known/Unknown.

▼
☁️
Google Sheets + Drive

Nama, status, waktu & link foto bukti tersimpan otomatis via Service Account.

▼
⚙️
n8n (Docker)

Google Sheets Trigger → AI Agent + Gemini 2.5 Flash → HTTP Request ke WAHA API.

▼
💬
WAHA — WhatsApp HTTP API (Docker)

Gateway WhatsApp Web (scan QR) — menerima pesan user & mengirim notifikasi.

▼
📱
Pengguna

Cek kehadiran, lihat bukti foto, atau request notifikasi ketika seseorang terdeteksi.

7 Tantangan & Pembelajaran

Apa yang saya pelajari dari membangun sistem ini.

  • Stabilitas RTSP di WiFi — transport TCP + grab-drain pattern + auto-reconnect menyelesaikan masalah frame freeze acak.
  • Multi-threading pengenalan — antrian thread + centroid tracker menjaga FPS real-time tanpa memblokir main loop.
  • Angka vs lingkungan nyata — recall 69% menunjukkan sudut pandang wajah (menunduk) & koneksi internet masih membatasi, bukan sekadar masalah algoritma.
  • Workflow automation efektif — n8n menurunkan latensi distribusi informasi menjadi ~9 detik dari sinkronisasi data.
  • Keamanan kredensial — semua kredensial dipindah ke environment variables dan repo dipublikasikan tanpa data biometrik & foto asli.
